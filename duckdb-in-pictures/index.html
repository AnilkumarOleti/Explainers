DuckDB, in pictures

A database that reads by the column and lives inside your program.

No server to run. Nothing to set up. You point it at your data and ask questions about the whole table.

The problem

Databases get asked two kinds of questions.

Fetch one record. Or add up a whole table. How the data is laid out on disk decides which one is fast.

Most databases keep rows together, because apps fetch one record at a time. DuckDB keeps columns together, because analysis reads a few columns across every row.

Where it lives

It has no server.

Most databases are a separate program you install, start, secure and connect to. DuckDB is a library. Your program loads it and calls it directly.

The map

Two ideas, four corners.

Where it runs, and which kind of question it is built for. DuckDB was made for the bottom-right corner.

Why it is fast

Three habits.

Skips what it doesn't need

A question about price opens the price strip only.

Works in batches

It handles a couple of thousand values per step, which modern chips do very quickly.

Uses every core

One query is split across all the processor cores in your machine.

Files

Your files are already tables.

Point a query at a file. There is no import step.

SELECT city, avg(price)
FROM 'orders.parquet'
GROUP BY city;

It speaks ordinary SQL. Installing it in Python is one line: pip install duckdb.

Limits

Where it fits, and where it stops.

Good fit

  • Exploring big files on a laptop
  • Data larger than memory, since it can spill to disk
  • Notebooks, scripts and data pipelines
  • Analytics built into another app

Look elsewhere

  • Many people writing at once. One process writes to a database file at a time.
  • The back end of an app with constant small updates
  • Data that needs a cluster. DuckDB runs on one machine.

Small like SQLite. Reads like a data warehouse.

People call it "SQLite for analytics", and that phrase is the whole idea.

DuckDB is free and open source. Mark Raasveldt and Hannes Mühleisen created it at CWI, the Dutch national research institute for mathematics and computer science, and first released it in 2019. It is named after Wilbur, Hannes's pet duck.
