Kurt Gödel · Vienna · 1931

The sentence math can't prove

Card no.G
stamp here

This sentence can never be stamped PROVEN.

In 1930, a 24-year-old in Vienna named Kurt Gödel found a sentence like this hiding inside ordinary arithmetic.

It is true. The rules of math can never prove it. Fixing the rules only creates a new one.

I The dream

The problem

Hilbert's dream: a truth machine

Put in a few starting facts. Turn the crank. Out come proven truths, one after another, forever. Around 1920 David Hilbert, the most famous mathematician alive, wanted all of math to work like this.

Wir müssen wissen. Wir werden wissen.We must know. We will know.

David Hilbert, radio address, Königsberg, 8 September 1930. The words are carved on his gravestone.

Look closer

Hilbert didn't want a literal machine. He wanted every part of math written as rules so precise that a machine could, in principle, check any proof. Then he wanted to prove, once and for all, that those rules were safe. This plan was called Hilbert's program.

How the machine works

Starting facts, plus rules. Nothing else.

Starting facts (axioms)

0 is a number
every number has a next
x + 0 = x
x + next(y) = next(x + y)

Rules (allowed moves)

swap equals for equals
if A, and A means B, then B

A proof of 1 + 1 = 2

  1. starting fact1 + 0 = 1
  2. starting fact1 + 1 = next(1 + 0)
  3. swap equalsnext(1 + 0) = next(1) = 2
  4. chain them1 + 1 = 2Proven

Even 1 + 1 = 2 is a chain of tiny allowed moves. A machine can check every link without understanding any of it. Mathematicians call this a formal system.

Look closer

The starting facts above are part of the Peano axioms (1889), the standard rulebook for whole numbers. "Next" means "add one", so 1 is next(0) and 2 is next(1).

The goal

Two lights Hilbert wanted on

Completeevery true sentence gets stamped
Consistentnever stamps a sentence and its opposite
Can't have both

Hilbert wanted both lamps lit for arithmetic. Gödel proved that if the consistent lamp is on, the complete lamp has to be off.

The key distinction

True and proven are different piles

True means that's how numbers really behave. Proven means the machine stamped it. Hilbert hoped the two piles were identical. Gödel found card G: true, and never stamped.

II The trick

How Gödel built card G, in four moves.

Move 1 of 4

Turn every sentence into a number

Sentence, symbol by symbol

    Multiply it all out

    Codebook · tap a symbol to add it

    Each position gets the next prime: 2, 3, 5, 7… Raise it to the symbol's code number, then multiply. Every number splits into primes in exactly one way, so you can always turn the number back into the sentence.

    Look closer

    This is called Gödel numbering. The codes themselves are arbitrary; any fixed codebook works. What matters is the consequence: a statement about numbers can now secretly be a statement about sentences.

    Move 2 of 4

    Proofs become arithmetic too

    A new sentence of arithmetic

    PROVABLE(m)

    "Some number is the code of a proof of sentence #m."

    A proof is just a list of sentences, so it gets one number too. Checking "is n a proof of sentence m?" only needs multiplying, dividing and comparing. So arithmetic can now talk about its own proofs.

    Look closer

    This is the long, technical heart of the 1931 paper. Gödel builds dozens of definitions, each from the ones before, ending with one he names Bew, short for the German beweisbar, "provable".

    Move 3 of 4

    Build a sentence that talks about itself

    A phrase

    is unprovable when placed after its own quotation

    The sentence you get= G

    "is unprovable when placed after its own quotation" is unprovable when placed after its own quotation.

    the quotationthe phrase

    Which sentence does G describe? "The phrase, placed after its own quotation." That is G itself. Gödel built the same thing in arithmetic: G says "sentence number g has no proof", and g is G's own number.

    Look closer

    No paradox or magic is needed, only copying and substituting, which arithmetic can do. The quotation version was made popular by the philosopher W. V. Quine. Logicians call the general recipe the diagonal lemma.

    Move 4 of 4

    Now ask the machine about G

    G"I can never be stamped PROVEN."

    If the machine stamps G…

    GProven

    …then G was wrong about itself. The machine just stamped a false sentence.

    The machine lies

    If it never stamps G…

    Gno stamp

    …then G is exactly right. G is true, and has no proof.

    A truth is missed

    Gödel's first incompleteness theorem

    Any consistent set of rules strong enough to do arithmetic leaves some true statement it can never prove.

    Look closer

    "Lies" here means stamping something false. Gödel's actual proof needs even less: only that the machine never contradicts itself, plus a technical condition that J. Barkley Rosser removed in 1936 with a cleverer sentence.

    III The fallout

    What follows, and what doesn't.

    The obvious fix

    Just add G as a new rule?

      Adding G gives you a new machine. The new machine has its own unprovable sentence. Add that one too, and another appears. Forever.

      Look closer

      Even adding infinitely many new rules doesn't help, as long as some program can list them all. Only a rulebook that no program can list escapes, and nobody could actually use one to check proofs.

      The second theorem

      The machine can't vouch for itself

      A consistent machine can never prove "I am consistent". A bigger machine can vouch for it, but can't vouch for itself. This ended Hilbert's hope that math could certify its own safety from the inside.

      Look closer

      The fork argument can be written inside the machine as "if I'm consistent, then G is true". So if the machine could prove its own consistency, it would prove G, which it can't. In 1936 Gerhard Gentzen did prove arithmetic consistent, by using a stronger kind of counting that arithmetic itself lacks.

      Start at

      True

      Every Goodstein sequence comes back down to 0.Reuben Goodstein, 1944

      Unprovable

      …using only the rules of ordinary arithmetic.Laurie Kirby & Jeff Paris, 1982

      No self-reference trick here. Just a simple rule about numbers that is true, and that arithmetic's own rulebook can't prove.

      Other real ones

      Paris–Harrington, 1977A puzzle about colouring sets of numbers. True, unprovable in ordinary arithmetic.
      The continuum hypothesisIs there a size of infinity between whole numbers and points on a line? Standard set theory can't settle it either way (Gödel 1940, Cohen 1963).
      Look closer

      "Powers of the base" goes all the way down: exponents get rewritten too, so 2² becomes 3³. The proof that every sequence reaches 0 counts past infinity using ordinals, a tool ordinary arithmetic doesn't have.

      The same idea, for computers

      Turing's halting problem

      Perfect checker reads any program and says "it halts" or "it runs forever"
      ⇄
      ProgramTROUBLE
      ask the checker about TROUBLE
if it says "halts"  → run forever
if it says "forever" → stop

      Whatever the checker predicts, TROUBLE does the opposite. So a perfect checker can't exist. Alan Turing showed this in 1936 with Gödel's self-reference trick. It is why no tool can find every bug in every program.

      Common misreadings

      What it does not say

      Myth

      Math is broken.

      Nearly all everyday math is proven as usual. Incompleteness lives at the edges.

      Myth

      Some truths can never be known.

      G is unprovable in its own machine. A bigger machine proves it easily.

      Myth

      It applies to everything: law, physics, life.

      Only to formal rulebooks that pass all three gates above.

      Myth

      It proves minds beat computers.

      A famous argument by Lucas and Penrose. Most logicians reject it.

      How it happened

      Ten dates

      1. 1900

        Hilbert lists 23 great open problems. Number 2: prove that arithmetic never contradicts itself.

      2. 1910

        Russell and Whitehead begin publishing Principia Mathematica, an attempt to build all of math from logic.

      3. 1920s

        Hilbert's program: write math as checkable rules, then prove those rules safe.

      4. 19307 September

        At a conference in Königsberg, Gödel, aged 24, briefly mentions his result. John von Neumann is one of the few who grasps it.

      5. 19308 September

        Same city, next day. Hilbert's radio address ends: "We must know. We will know."

      6. 1931

        The paper appears: On Formally Undecidable Propositions of Principia Mathematica and Related Systems I.

      7. 1936

        Turing's halting problem. Gentzen proves arithmetic consistent from outside. Rosser sharpens Gödel's theorem.

      8. 1940and 1963

        Gödel, then Paul Cohen, show standard set theory can't settle the continuum hypothesis.

      9. 1977

        Paris and Harrington find a natural, true statement that ordinary arithmetic can't prove.

      10. 1982

        Kirby and Paris show the same for Goodstein's theorem.

      The picture to keep

      Truth is bigger than proof

      Every new rule grows the stamped pile. A new G always sits just outside it.

      The whole idea on one card

      A machine that only stamps true things can never stamp the card that says "you can't stamp me".

      Gödel didn't break mathematics. He proved it can never be finished.
